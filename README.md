# 📚 Revisão de Conceitos Matemáticos

Um programa destinado ao apoio à aprendizagem por meio de revisões teóricas e aplicações práticas.

---

## 📖 Sobre o projeto

A Matemática é uma das disciplinas que apresenta grandes desafios para os estudantes do Ensino Médio, principalmente devido à complexidade de alguns conteúdos, à necessidade de conhecimentos prévios e às dificuldades encontradas durante o processo de aprendizagem.

Diante desse cenário, o projeto **Revisão de Conceitos Matemáticos** tem como objetivo desenvolver um programa educacional que auxilie os estudantes no aprendizado da Matemática, por meio de revisões teóricas e aplicações práticas.

A proposta busca tornar o estudo mais acessível e facilitar a compreensão dos conteúdos, permitindo que os alunos revisem conceitos e pratiquem seus conhecimentos de maneira interativa.

## 🎯 Objetivos

- Auxiliar os estudantes no aprendizado da Matemática.
- Facilitar a compreensão dos conteúdos matemáticos.
- Disponibilizar revisões teóricas.
- Oferecer aplicações práticas por meio de calculadoras.
- Incentivar o estudo e a prática dos conceitos apresentados.

## 📐 Conteúdos abordados

O programa contempla os seguintes conteúdos matemáticos:

- **Regra de Três:** processo matemático utilizado para resolver problemas que envolvem grandezas diretamente ou inversamente proporcionais.
- **Fórmula de Bhaskara:** utilizada para encontrar as raízes de uma equação do segundo grau.
- **Geometria Plana:** estudo das figuras geométricas planas e cálculo de suas áreas.
- **Potenciação:** operação matemática que representa a multiplicação de fatores iguais.
- **Logaritmo:** operação matemática utilizada para descobrir o expoente ao qual uma base deve ser elevada para obter determinado resultado.
- **Juros Simples:** acréscimo calculado sobre o valor inicial de uma aplicação financeira ou dívida.
- **Juros Compostos:** sistema de capitalização em que os juros são adicionados ao capital a cada período.
- **Fração:** representação das partes de um todo, divididas em partes iguais.
